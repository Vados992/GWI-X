# Работа с проектом

Ветка `main` содержит опубликованный расчётный пакет. Изменения готовятся в отдельной ветке и проходят pull request с проверками GitHub Actions. Не заменяйте отсутствующие реальные наблюдения синтетическими под видом официальных данных.

Перед изменением формул прочитайте [технический отчёт](docs/technical_report_ru.md), [словарь размерностей](docs/data_dictionary_ru.md) и [границы источников](docs/sources.md).

```text
python -S -m unittest discover -s tests -v
python -S scripts/ci_check.py
```

Вторую команду запускайте из чистой копии репозитория: она создаёт новую папку `results-local/ci`, исполняет полный расчёт дважды и сверяет его с опубликованными CSV. Для повторного локального прогона используйте новую копию или перенесите предыдущие локальные результаты самостоятельно.

Ожидаемые остановки `debt_stress` и `zero_funding` входят в сценарную спецификацию. Их нельзя «исправлять» вымышленным финансированием или нулями вместо неизвестного будущего.

Меняя модель, обновляйте смысловые тесты, результаты, разрешённые конфигурации и документацию вместе. Простое изменение ожидаемых чисел без объяснения причины не подтверждает исправление. При изменении контрольных CSV пересчитайте вложенные SHA-256-манифесты и корневой манифест.

На одной среде численные CSV и конфигурации должны совпадать побайтно. Между разными ОС допускается только явно заданная малая погрешность плавающей точки: `rel_tol=1e-12`, `abs_tol=1e-8`. Национальные денежные тождества дополнительно проверяются абсолютным допуском 0.0001 CU внутри каждого запуска.

Все публичные примеры остаются синтетическими. Данные страны, национальные ставки и правовые выводы подключаются только отдельной проверяемой работой с разрешёнными источниками.

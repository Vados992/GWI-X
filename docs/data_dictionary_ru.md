# Размерности, поля и вычислительные соглашения

Все суммы — в вымышленных **CU**. Под CU не подразумеваются евро или валюта выбранной страны. Реальные CU выражены в ценах 2027 года. Один шаг — один год; годовые денежные потоки нельзя складывать со стоимостями запасов без уравнения движения запаса.

## Основные единицы

| Величина / поля | Единица и смысл |
|---|---|
| `year` | Условный календарный год; 2027–2036 |
| `cpi` | Безразмерный уровень цен, 2027 = 1; на графике умножен на 100 |
| `inflation`, `inflation_next` | Годовая доля изменения CPI; 0.02 = 2%; первая — текущая, вторая — следующего года |
| `gdp_real`, `potential_real` | Поток CU базового года / год |
| `gdp_nominal` | Поток текущих CU / год; `gdp_real*cpi` |
| `capital_open_real`, `capital_close_real` | Запас производительного капитала в CU базового года на начало / конец года |
| `productivity`, `productivity_next` | Индекс TFP, начальное значение 1 |
| `labor_productivity_real_per_worker` | Фактический реальный выпуск / занятые, CU базового года на работника / год; не TFP |
| `output_gap` | `gdp_real/potential_real-1`, доля |
| `consumption_real`, `private_investment_real`, `public_investment_real`, `government_consumption_real`, `other_demand_real` | Компоненты фактического выпуска, CU базового года / год |
| `policy_rate`, `interest_rate` | Годовые номинальные доли; первая — условная макрореакция, вторая — ставка по государственному долгу |
| `private_investment_floor` | 1, если отрицательная плановая инвестиция заменена физическим нижним пределом 0; 0 иначе |
| `debt_open`, `debt_close` | Валовой номинальный долг, CU на начало / конец года |
| `reserve_open`, `reserve_close` | Запас ликвидных средств программы, номинальные CU |
| `treasury_open`, `treasury_close` | Запас общих казначейских денег, номинальные CU |
| `debt_gdp` | Конечный номинальный долг / номинальный ВВП за этот год, доля; не долг / реальный ВВП |
| `revenue`, `expenditure`, `interest`, `vat`, `other_tax` | Национальные денежные потоки, текущие CU / год |
| `legacy_subsidy` | Оставшиеся после перераспределения выплаты исходного пула субсидий фирмам, текущие CU / год |
| `government_consumption_nominal` | Государственное конечное потребление, текущие CU / год |
| `deficit` | `expenditure-revenue`, текущие CU / год; положительное значение — дефицит |
| `primary_balance` | `revenue-expenditure+interest`, текущие CU / год; положительное значение — первичный профицит |
| `borrowing`, `debt_repayment` | Привлечение нового долга и погашение номинала, текущие CU / год; проценты отдельно |
| `treasury_draw`, `treasury_deposit` | Расходование и увеличение казначейских денег, текущие CU / год |
| `funding` | Внутренний перевод из перераспределённого пула в программу, текущие CU / год; не дополнительные консолидированные доходы |
| `income_fund` | Выплаты надбавки семьям, текущие CU / год |
| `social_clearing` | Внутреннее возмещение социальной системе выпадающих взносов, текущие CU / год; не вторая выплата семье |
| `investment`, `admin` | Финансируемые расходы программы, текущие CU / год |
| `deposit`, `withdrawal` | Пополнение и расходование ликвидного резерва, текущие CU / год; движения финансового актива |
| `return_to_treasury` | Неиспользованный внутренний перевод обратно в казначейство, текущие CU / год |
| `multiyear_margin_real` | Минимальный годовой ресурс оставшегося горизонта минус верхняя граница годовой стоимости назначенной группы, базовые CU / год |
| `admitted_households`, `new_households` | Взвешенное число семей с назначением / новых назначений; назначение не означает занятость или выплату в каждом году |
| `gate_*` | 1 — расширение допущено по данному критерию; 0 — остановлено. Все активные критерии должны пройти |
| `gate_reasons` | Причины запрета расширения; `OPEN` означает, что общие критерии открыты, но индивидуальные ограничения и лимит EMTR продолжают действовать |
| `*_residual` | Остаток соответствующего тождества; денежные — CU, `gdp_identity_residual` — реальные CU / год |

## Микроуровень и национальное взвешивание

В `households.csv` `gross`, `income_tax`, `employee_sc`, `employer_sc`, `business_sc`, `clearing`, `topup`, `benefits`, `pension`, `disability`, `child`, `assistance`, `disposable`, `employer_cost` — **текущие CU на одну семью за год**. `real_disposable` — базовые CU на семью за год. Это суммы всех взрослых семьи, а не сумма на каждого взрослого.

`gross` — трудовой доход до личных налогов и взносов. `employer_sc` оплачивается работодателем сверх gross. `business_sc` — аналогичный взнос самозанятого, вычитаемый из его располагаемого дохода. Поэтому `employer_cost` охватывает только наёмных работников; он не является стоимостью труда самозанятого.

`weight` — сколько реальных по размеру, но **синтетических** семей представляет одна запись. Сумма весов = 1 млн. `employed` и `labor_eligible` в семье — числа взрослых; `children` — число детей. В `annual.csv` префикс `hh_` у денежных полей означает сумму `weight*household_value` по населению. Исключения: `hh_employment` и `hh_labor_force` — люди, `hh_employment_rate` — доля.

`employment_rate` — занятые / потенциально участвующие взрослые, исключая постоянные группы пенсионеров и инвалидности. Это внутреннее определение модели; его нельзя выдавать за официальную национальную долю занятости или безработицы ILO.

`emtr_adults` — ставки каждого взрослого при отдельном увеличении его gross на 100 базовых CU в номинальном эквиваленте. В ходе пробного расчёта не меняются занятость, другие заработки и назначение программы. `emtr` — наибольшая определённая ставка в семье. `emtr_weighted` — среднее этих семейных максимумов по весам работающих семей; это не средняя ставка всех работников. `emtr_above_gate_households` — взвешенное число работающих семей выше порога.

`groups.csv`: `households` — сумма весов; `real_disposable_mean`, `nominal_disposable_mean` — среднее на семью; `employment` — взвешенные люди; `topup` — национальная сумма текущих CU / год. Группы взаимоисключающие, их определения зафиксированы до моделирования исходов. Групповые средние не эквивалентны доходу типичного человека и не показывают внутригрупповые потери.

## Конфигурация и сравнения

Все `*_real` в конфигурации выражены в базовых CU; пороги и выплаты домохозяйствам — CU на человека/семью за год согласно названию. `wage_real_hour` во входной таблице — CU базового года / час; `hours_year` — часы / год. `years` — число шагов. Ставки — доли, не проценты. `seed` — целое число генератора.

`funding_multipliers` — доля исходного доступного источника. `demand_shocks` умножают прочий спрос на `1+shock`; `supply_shocks` — потенциальный выпуск. `inflation_shocks` добавляются к доле следующей инфляции, `labor_shocks` — к вероятности расставания с работой следующего шага, `interest_shocks` — к годовой ставке долга. Нельзя интерпретировать одинаковое число в разных массивах как одинаковый тип шока.

В `comparisons.csv` поля `*_change_pct` — `100*(reform/control-1)`, проценты изменения уровней. Поля `*_change_pp` — `100*(rate_reform-rate_control)`, **процентные пункты**. Сопоставляются только годы, которые успешно завершены в обоих расчётах. Неизвестные будущие результаты остановленного сценария не заполняются нулями.

Сохраняется двоичная арифметика Python, без округления промежуточных миллиардных сумм до центов. Допуск денежных тождеств — 0.0001 CU; это вычислительная модель, а не бухгалтерская система для денежных переводов. Округление в отчёте не изменяет CSV.
